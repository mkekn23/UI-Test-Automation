# UI-Test-Automation

3.1 Why Automate This? - 25 pts

For each automated scenario, explain its risk, business value, and why UI automation is appropriate.

3.2 Selector Strategy - 25 pts

Describe three to five key selectors, why they are stable, what could break them, and your locator priority.

3.3 Flaky Test Awareness - 25 pts

Select one test and explain its potential sources of flakiness and how you prevented them.

3.4 Mobile is not Desktop - 25 pts

For one scenario, explain mobile-specific behavior, different assertions, and user experience risks.
